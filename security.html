Security, Optimization, and Monitoring

1-1. Security Enhancement: XSS Attack Prevention

Technical Detail: All user-provided data is treated as a potential threat. To prevent attackers from injecting <script> tags to steal session cookies or deface the page, I implemented a sanitization process using JavaScript's replace function. This converts special characters like < and > into HTML Entities (&lt;, &gt;), ensuring the browser interprets them as literal text rather than executable code. This is a fundamental defense mechanism following OWASP security guidelines.

1-2. Session Security & CSRF Protection

Technical Detail: To protect user sessions, I simulated the implementation of Secure & HTTP-only Cookies and CSRF Tokens. In a production environment, 'HTTP-only' prevents JavaScript from accessing cookies (defending against XSS cookie theft), and 'Secure' ensures cookies are only sent over encrypted HTTPS. Additionally, a unique CSRF Token is validated for every sensitive request to ensure the action is performed by the legitimate user, not a malicious third-party site.

2. Performance Optimization: CDN & Lazy Loading

Technical Detail: Website loading speed is critical for user experience and network efficiency. By using the loading="lazy" attribute, images outside the viewport are deferred from downloading, which minimizes initial Bandwidth consumption. Additionally, Cloudflare CDN is utilized to cache content across global edge servers. This ensures users receive data from the physically closest server, drastically reducing Latency and improving overall Throughput.

3. Network Monitoring: Google Analytics Integration

Technical Detail: Visibility is key to network management. Integrating Google Analytics allows for real-time monitoring of traffic sources, locations, and device types. Beyond simple visitor counting, this serves as a primary security analysis tool to detect anomalies, such as sudden traffic spikes, which could indicate potential DDoS or bot attacks. Collected data enables evidence-based decisions for optimizing server resource allocation.
